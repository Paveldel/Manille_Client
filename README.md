# Manille Client

This is the client project for my manille game. You can find the server project [here](https://github.com/Paveldel/Manille_Server).

## Quick start

This project uses plain html, css and javascript. To host the site you can simply clone the repository and host the files on a simple webserver. Be sure to also have the server running.

In `/assets/js/config.js` there is a constant for the API url, please change this url to match where you are running the server.

Finally and most importantly you will need to find three good friends to play with!

## Playing the game

When reaching the game's website you will see the following title screen:

![title screen](/readme/titlescreen.png)

Creating a game can simply be done by entering your username and clicking the play button underneath.

When creating a game you will see the text "waiting for other players to join" and the game id of your game below. Share this game id with your friends.

To join a game you fill out the game id along with your username in the respective fields and press play.

![title screen](/readme/trump.png)

In the game you will need to follow the rules of the classical manille game. There are lots of good resources to learn to play. You can find a few here:  
[Whisthub](https://www.whisthub.com/manille/rules), [Extremis](https://www.extremis.com/en/stories/playing-manille) or [Wikipedia](https://en.wikipedia.org/wiki/Manille)

This site only allows you to play the four player variant. The order in which you join the game will determine who your teammate is.

![title screen](/readme/playing.png)

When playing cards you will go from left to right, and back around. Players 1 and 3 will make the first team, leaving players 2 and 4 for the other.

When you've had your fun you can leave the room. You cannot join the room again later so please only do this when you've completed the game.

If something happens and you need to rejoin. You will automatically reconnect to the game you were playing.
